# API First

Prioritise APIs in the development process, mean that we start thinking of designing them before writing the code, i.e what would be the resources, how to organize the URLs, what are we going to return to the consumers. Here we map out the API surfaces and then build the implementation.

- Focus on the needs of the API consumers from the start

- Ensures uniformity across different APIs and services. we define best practices or guildeline that you want to follow 

- API First encourages collaboration between teams and stakeholders
